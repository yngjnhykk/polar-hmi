v4

3D 디지털 트윈 예지정비 플랫폼 (현재 개발본)

계획서상 SW 기능 3종을 앞에 둔 육상 관제 플랫폼. 선체·추진계를 3차원으로 보고, 거기서 잔여수명과 정비 일정으로 이어집니다.

  • 기능 1 — 선체 누적 피로 & 추진계 응력 3D 시각화 (구역별 손상 히트맵 · 회전·확대·클릭)
  • 기능 2 — 선체/추진계 잔여수명: 구조 6요소(Miner 누적) + 부품(2계층)을 한 표에
  • 기능 3 — 정비 스케줄링 · 의사결정: 기항 간트 · 부품 정비 + 구조 검사 통합 큐
  • 받치는 화면 — 선단 위치 · 채널 상세 · 레퍼런스 진단 · 장비 BOM · 데이터 품질 · 리포트
 v3

모니터링 (v3 · 화면 8장)

지도를 중심에 둔 관제 화면. 보이는 값을 최소로 줄이고, 판정에 필요한 것만 남겼습니다.

  • 선단 위치 — 2D 지도 · 24시간 항적 · 드래그 이동 · 휠 확대
  • 채널 상세 — 정의서 200채널 + 부경대 DAQ 18개 조회 · 검증 범위 · 추세
  • 레퍼런스 커브 진단 — 0점 평탄화 잔차(±3/5/10 %) · 구간 분할 과도응답(도달시간 비율)
  • 잔여수명 — 2계층 계산(설계수명 − 등가 운행량 + 실측 보정) · 4단계 경보 · 책임자 확인
  • 정비 권고 — 조치 · 기한 · 추천 기항(결빙 폐쇄 · 입거 · 정박 시간 판정)
  • 장비 BOM — 부품 마스터 수정 · 검증 · 정비 이력(교체 시 잠금 해제)
  • 데이터 품질 — 수신률 · 결측 · 범위 밖 · ISO 19848 Local ID 구문 검사
  • 리포트 — 주간 종합 · 데이터 품질 보고서(A4 인쇄)
 v2

초기 프로토타입 (v2 · 비교용)

8개 화면을 모두 갖춘 이전 버전. 사이드바 아래에서 핵심(v2) · 전체(v1) 화면을 바꿔 볼 수 있습니다.

  • 선단 관제 · 데이터 품질 · 리포트 · 알람 센터
  • 잔여수명 현황 · 레퍼런스 커브 진단 · 정비 계획 · 장비 이력

두 화면 모두 목(mock) 데이터로 동작하는 시연본입니다. 선박 위치는 정의서에 위경도 채널이 없어 가정값이며, 부품·설계수명·기항 일정·경보 임계도 실제 자료를 받기 전의 가정값입니다.
